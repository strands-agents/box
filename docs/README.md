# Box documentation

Two guides. For any page, ask whether the reader needs it to **use** Box, or to
**trust or change** Box.

| Guide | Answers | Reader |
|---|---|---|
| [`user/`](./user/) | How do I use it? | An operator who runs an agent or another command under a policy. Being rewritten: only getting started is current. |
| [`design/`](./design/) | How does it work, and why should I trust it? | A security evaluator, a contributor, or someone who is curious. |

Technical does not mean design. The reference an operator needs to run Box, the
`box.toml` keys, the CLI, and the policy vocabulary, belongs in the user guide. The
reasoning behind those same topics belongs in the design guide.
